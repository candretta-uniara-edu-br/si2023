Como participar do projeto

Esta página resume o processo para cada aluno criar seu currículo e publicar sua contribuição no repositório.

Antes de começar

  1. Solicite acesso ao repositório criando uma issue em github.com/candretta-uniara-edu-br/si2023/issues/new.
  2. Na issue, informe corretamente seu e-mail institucional @uniara.edu.br.
  3. O acesso é liberado apenas para alunos da Uniara com e-mail institucional válido.
  4. Depois da liberação, aceite o convite em github.com/settings/repositories.
  5. Clone o projeto usando GitHub Desktop.
  6. Abra a pasta do projeto no VS Code.

O que você precisa editar

  1. Copie `curriculos/modelo.html` para um novo arquivo com seu nome.
  2. Edite a cópia com os seus dados.
  3. Opcional: atualize a página `alunos.html` adicionando um card (um `article` dentro de `div#lista-alunos`) apontando para o seu arquivo em `curriculos`.
  4. Recomendação: use nomes de arquivo sem espaços, com hifens, por exemplo `nome-sobrenome.html`.
  5. Não altere nem renomeie o arquivo original `curriculos/modelo.html`.

Cuidados importantes

  • Use sempre o mesmo e-mail `@uniara.edu.br` na solicitação, no convite e no acesso ao repositório.
  • Não altere nem renomeie o arquivo original `curriculos/modelo.html`.
  • Não altere a estrutura principal do modelo sem necessidade.
  • Confirme se o currículo abre corretamente.
  • Se houver conflito de código, revise o HTML com atenção antes de enviar.

Como testar

Depois de criar seu arquivo dentro de curriculos, digite a URL completa no navegador usando o nome do arquivo criado.

Exemplo: https://candretta-uniara-edu-br.github.io/si2023/curriculos/maria-souza.html

Checklist final

  1. Seu currículo está dentro da pasta `curriculos`.
  2. O novo arquivo foi criado a partir de `curriculos/modelo.html`.
  3. O arquivo original `curriculos/modelo.html` permanece intacto.
  4. O currículo abre corretamente pela URL completa.
  5. Você fez commit com uma mensagem clara.
  6. Você enviou as alterações para o repositório.
