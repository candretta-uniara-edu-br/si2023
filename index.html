Projeto da turma

Um espaço para apresentar a turma e os currículos.

Este site foi organizado para facilitar atividades didáticas com HTML, CSS, jQuery, versionamento e publicação de páginas individuais.

Ver lista de alunos Como participar

Objetivos do projeto

  • Praticar a estruturação de páginas web estáticas.
  • Manter um cadastro simples e legível dos alunos.
  • Permitir que cada aluno publique seu próprio currículo.
  • Facilitar manutenção e evolução do conteúdo em sala.

Como funciona

Cada aluno cria sua página de currículo e edita manualmente a lista em HTML, praticando a estrutura real do código e o fluxo de colaboração no repositório.

Organização

Os currículos ficam dentro da pasta curriculos, enquanto os estilos e scripts permanecem separados para facilitar entendimento e manutenção.

Uso didático

A proposta é deixar o projeto enxuto e claro, para que os alunos consigam localizar rapidamente onde editar cada informação.
